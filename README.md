# 2ml.ai

The 2ML marketing site: a Next.js app exported as a static site and served by Cloudflare Pages.

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
```

## Checks

```bash
npm run build   # static export into out/
npm run lint
npm test        # Playwright against the built export, not next dev
```
